What the corpus exposed

Semantic coverage is the limiting factor

Manual blockers and unsupported effects account for 305 of 377 rejected files. This is not configuration cleanup; the next material gains require focused semantic recipes and AI-assisted review.

Correctness regressions are now concrete

Nerimity gives a syntax regression fixture for effect rewriting. Nerimity and Primal both prove the store pass can defer transformations until pass two. Primal exposes a CRLF/printing defect that turns a focused migration into a noisy, invalid patch.

These should become reduced fixtures before expanding recipe coverage.

Dependency migration needs graph awareness

Two apps could not resolve Solid 2 alongside Solid 1-only ecosystem peers. OpenAQ installed, but a consumer still depended on a removed renderer subpath. Updating only first-party manifest entries is not enough to produce an installable graph.

Baseline quality must remain explicit

Only Primal had a completely valid baseline in this environment. Validator and idempotency findings remain valid for all apps, but build deltas for missing-lockfile, registry-timeout, or Node-engine cases are deliberately classified as inconclusive.

Recommended next implementation order

  1. Make validation failures propagate. The workflow must exit nonzero when its validator fails. Until then, keep the direct validator as the authoritative gate.
  2. Reduce and fix the two correctness bugs. Add a Nerimity-derived malformed-effect fixture, then fix the multi-pass store ordering seen in Nerimity and Primal.
  3. Preserve file trivia. Add CRLF fixtures and guarantee line-ending/trailing-whitespace stability before running on large Windows-authored codebases.
  4. Add repository discovery and a dependency migration manifest. Detect app/workspace roles, enumerate Solid ecosystem packages, classify peer compatibility, and stop before lock regeneration when the graph is known-incompatible.
  5. Build focused semantic recipes from the 305-file majority. Cluster S2-VALIDATE-001 blocker subtypes and S2-VALIDATE-002 effect shapes, automate only high-confidence groups, and route the rest through structured AI review.
  6. Promote this corpus to a pinned canary suite. Keep exact SHAs, a frozen codemod snapshot, direct validation, second-pass hashing, and baseline/post command symmetry. Use the reserve apps to test desktop and directive-heavy paths next.

Method and evidence

The frozen snapshot passed 6 configuration fixtures, 31 source fixtures, 1 clean validator fixture, 5 expected validator failures, and TypeScript checking before corpus execution. Each trial used a disposable copy, preserved the discovery checkout, captured the first patch, invoked the validator directly, reran the workflow for byte-level idempotency, and attempted lock/install/build/test checks when the baseline allowed it.
