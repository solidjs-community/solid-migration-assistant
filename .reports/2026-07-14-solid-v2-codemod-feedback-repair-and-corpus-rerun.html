What the implementation changed

Binding and scope safety

  • Removed global imported-name replacement.
  • Preserves local aliases for mergeProps, batch, and async boundaries.
  • Scopes selected splitProps reads to the nearest lexical block.
  • Protects sibling functions that reuse names such as props.

Correct mechanical recipes

  • Router rest-only splitProps becomes const rest = omit(props, ...keys).
  • Direct Babel preset, runtime, renderer, plugin, dev, and peer policies migrate by package role.
  • Unsupported effects reconcile nested setter edits in one pass.
  • Private workspace roots receive an explicit beta.17 development tuple.

Fail-closed semantic boundaries

  • Complex lifecycle, directive, props, async, store, and effect shapes emit coded blockers.
  • Cross-file <Context.Provider> forms are rejected rather than guessed.
  • Cross-file directive families require semantic migration.
  • Router cache/navigation algorithms and obsolete-module deletion remain outside the mechanical pass.

Validator and evidence

  • Verified beta.17 exports instead of assuming removals; onCleanup remains valid.
  • Detects proven removed exports including on, catchError, resetErrorBoundaries, and createComputed.
  • Expected-failure validator fixtures exercise rejection.
  • Every config/source fixture is second-pass hash checked.

What improved relative to the earlier trials

Fixed

False-clean validation

Router and Primitives now stop on real unsupported forms. Router reports five real files; Primitives reports 138 scoped failures. The false onCleanup rule was removed after beta.17 runtime and type verification.

Fixed

Dependency and compiler coherence

Router’s direct Babel preset now moves to beta.17, and its built output no longer reintroduces solid-js/web. Primitives’ private root and 88 library manifests receive Solid/renderer policy; missing @solidjs/web errors fell to zero.

Fixed

Known transform corruption

Router splitProps output is valid, merge/batch collisions are avoided, lifecycle ambiguity blocks rather than corrupts syntax, and Primitives’ first pass is now idempotent.

Still open

Semantic closure

Router’s 65 runtime failures are unchanged because old navigation, cache, async, ownership, and scheduling algorithms remain. Primitives now executes more Solid 2 code, exposing hundreds of real semantic/type failures instead of missing-module collection errors.

Remaining highest-priority work

  1. Wrap workflow execution with an authoritative gate. The Codemod workflow runner still exits 0 after validator failures. A project-owned runner must execute the validator directly and propagate nonzero status.
  2. Implement workspace discovery and a migration manifest. Primitives’ site/package.json was the sole skipped manifest while twelve site files gained renderer imports. Package/source scope must be decided before mutation.
  3. Pass package role into source transforms. Application compatibility helpers such as storePath should not silently define publishable-library architecture.
  4. Add structured rule metrics and blocker budgets. Record applied, skipped, ambiguous, blocked, and already-migrated cardinalities per package and assert them in fixtures/corpus gates.
  5. Build semantic recipes as transactions. Directive definitions/exports/call sites, presence effects and cleanup, Router cache/navigation, ownership, public APIs, tests, and deletion must migrate together.
  6. Consolidate the executable architecture. Port the green tracer bullet into focused packages and expose only implemented phases through the thin recipe; then add frozen root CI.
